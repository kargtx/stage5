## 1. Как настроена система (Двухуровневая защита)

Для выполнения задания настроена железная двухуровневая фильтрация:

### А. Разрешающие правила (ТОЛЬКО для Данила `10.8.1.11`):
1. **`STAU_LR5_ICMP_Allow_Danil`** — разрешает ping и traceroute (ICMPv4 Echo Request).
2. **`STAU_LR5_SMB_TCP_Allow_Danil`** и **`STAU_LR5_SMB_UDP_Allow_Danil`** — разрешают доступ к общей папке `STAU_Share` (`C:\STAU_LR5_Shared`, порты TCP 445, 139, UDP 137, 138).
3. **`STAU_LR5_RemoteReg_TCP_Allow_Danil`** — разрешает подключение сетевого реестра (RPC TCP 135, 445, 49152-65535, служба `RemoteRegistry`).
4. **`STAU_LR5_RDP_TCP_Allow_Danil`** и **`STAU_LR5_RDP_UDP_Allow_Danil`** — разрешают удаленный рабочий стол (порт 3389, служба `TermService`).

### Б. Явные блокирующие правила (ДЛЯ ВСЕХ ОСТАЛЬНЫХ УЗЛОВ):
Поскольку в Windows Defender Firewall правила **Block имеют абсолютный приоритет над Allow**, созданы явные запрещающие правила с диапазоном адресов `10.8.1.1-10.8.1.10, 10.8.1.12-10.8.1.254` (весь локальный сегмент, исключая IP Данила):
1. **`STAU_LR5_ICMP_Block_Others`** — 100% блокирует ping и traceroute с любых других устройств.
2. **`STAU_LR5_SMB_Block_Others`** — 100% блокирует доступ к общим папкам.
3. **`STAU_LR5_RemoteReg_Block_Others`** — 100% блокирует удаленный реестр.
4. **`STAU_LR5_RDP_Block_Others`** — 100% блокирует удаленный рабочий стол.

## 2. Как показать настройки брандмауэра преподавателю

1. Нажмите **`Win + R`**, введите:
   ```text
   wf.msc
   ```
2. В разделе **«Правила для входящих подключений»**:
   * Покажите зеленые правила с префиксом **`СТАУ ЛР5:`** (в свойствах на вкладке «Область» указан IP `10.8.1.11`).
   * Покажите красные правила блокировки **`СТАУ ЛР5: Блокировка ... для остальных`** (в свойствах на вкладке «Область» указан диапазон остальных адресов `10.8.1.1-10.8.1.10, 10.8.1.12-10.8.1.254`).

## 3. Демонстрация с ноутбука Данила (`10.8.1.11`)

Данил со своего ноутбука выполняет 4 проверки:
1. **ping:** `ping 10.8.1.1` $\to$ **0% потерь, отклик ~3 мс** (Успешно).
2. **Общая папка:** `Win + R` $\to$ `\\10.8.1.1\STAU_Share` $\to$ вводит логин `danil`, пароль `12345` $\to$ **папка открывается, файл `welcome.txt` читается**.
3. **Удаленный реестр:** `Win + R` $\to$ `regedit` $\to$ Меню «Файл» $\to$ «Подключить сетевой реестр...» $\to$ `10.8.1.1` $\to$ **ветви HKLM и HKU подключаются**.
4. **RDP:** `Win + R` $\to$ `mstsc` $\to$ компьютер `10.8.1.1`, пользователь `danil`, пароль `12345` $\to$ **сессия удаленного стола открывается**.

## 4. Демонстрация блокировки остальных соседей (например, `10.8.1.12` или телефон)

Если любое другое устройство попробует подключиться к `10.8.1.1`:
1. `ping 10.8.1.1` $\to$ **«Превышен интервал ожидания для запроса»** (100% потерь).
2. `\\10.8.1.1\STAU_Share` $\to$ **0x80070035 («Не найден сетевой путь»)**.
3. `regedit` $\to$ **«Не удалось подключиться к 10.8.1.1»**.
4. `mstsc 10.8.1.1` $\to$ **«Удаленному рабочему столу не удается подключиться»**.

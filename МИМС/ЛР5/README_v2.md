4. **`advanced_analysis_dashboard.png`** — 4-панельный аналитический дашборд оптимизации.

7. **`Лабораторная работа5 ЭАС.pdf`** — исходная методичка кафедры.

## 1. Как открыть и запустить модель в AnyLogic:
1. Запустите AnyLogic 8.9.
2. Нажмите **Файл (File) -> Открыть (Open...)** и выберите файл:
   `МИМС\ЛР5\ServiceCenter_v2.alp`
3. В дереве проекта (слева) раскройте модель `ServiceCenter_v2`, дважды щелкните на агента **`Main`**:
   - На холсте сразу отобразятся все технологические зоны сервисного центра (Приемка, Очередь, Ремонтный цех, Выдача), дашборд и соединенная цепочка блоков библиотеки Process Modeling Library.
4. Для запуска симуляции нажмите зеленую кнопку **Запустить (Run)** в панели инструментов или правой кнопкой на эксперимент **`Simulation` -> Запустить**.

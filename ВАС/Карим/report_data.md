# Отчет по лабораторной работе "Организация параллельных потоков. Часть 1"

**Вариант:** 4
**Функция:** $f(x) = 0.05x^3 + 0.3x^2 - 20x + 200$
**Пределы интегрирования:** $A = -5, B = 20$

## 1. Теоретическая (аналитическая) часть

### 1.1 Грубая оценка площади
Рассчитаем значения функции на концах интервала и в его середине:
*   $f(-5) = 0.05(-125) + 0.3(25) - 20(-5) + 200 = -6.25 + 7.5 + 100 + 200 = 301.25$
*   $f(20) = 0.05(8000) + 0.3(400) - 20(20) + 200 = 400 + 120 - 400 + 200 = 320$

Среднее значение (очень грубо) $f_{ср} \approx (301.25 + 320) / 2 \approx 310$.
Ширина интервала = $20 - (-5) = 25$.
Грубая оценка интеграла: $S \approx 25 \times 310 = 7750$.

### 1.2 Аналитическое решение
Найдем первообразную функцию $F(x)$:
$F(x) = \int (0.05x^3 + 0.3x^2 - 20x + 200) dx = \frac{0.05}{4}x^4 + \frac{0.3}{3}x^3 - \frac{20}{2}x^2 + 200x$
$F(x) = 0.0125x^4 + 0.1x^3 - 10x^2 + 200x$

Вычислим значения первообразной на границах:
*   $F(20) = 0.0125(160000) + 0.1(8000) - 10(400) + 200(20) = 2000 + 800 - 4000 + 4000 = 2800$
*   $F(-5) = 0.0125(625) + 0.1(-125) - 10(25) + 200(-5) = 7.8125 - 12.5 - 250 - 1000 = -1254.6875$

Точное значение интеграла:
$S = F(20) - F(-5) = 2800 - (-1254.6875) = 4054.6875$

11: 2. Теоретическая часть
12: 2.1. Роль диагностики датчиков в АС СН
13: Датчики – это первичный источник информации в любой АС СН. Если датчик выдаёт недостоверные данные, вся система управления может принять ошибочное решение, что приведёт к аварии. Поэтому диагностика датчиков является обязательным элементом АС СН.
14: Диагностика может быть:
15: Встроенной – реализована внутри интеллектуального датчика;
16: Внешней – выполняется контроллером или SCADA-системой на основе анализа поступающих данных.
17: В данной работе мы реализуем внешнюю диагностику – алгоритм, который получает поток значений от датчика и определяет, исправен ли он.
18: 2.2. Классификация отказов датчиков
19: Явные отказы:
20: Обрыв цепи – сигнал падает до нуля или принимает значение вне допустимого диапазона (например, −50 °C для температурного датчика). В токовой петле 4–20 мА обрыв соответствует 0 мА.
21: Короткое замыкание – сигнал превышает максимально допустимое значение (например, 200 °C).
22: Выход за диапазон – значение выходит за пределы, физически возможные для данного процесса.
23: Скрытые отказы:
24: Дрейф нуля – медленное смещение показаний относительно истинного значения. Датчик «врёт» нарастающе, но остаётся в допустимом диапазоне. Это самый опасный тип отказа, потому что его трудно заметить без эталонного сравнения.
25: Дрейф чувствительности – коэффициент преобразования меняется, показания искажаются пропорционально.
26: «Залипание» – значение перестаёт меняться, хотя процесс продолжается. Датчик «замер» на последнем значении.
27: Перемежающиеся отказы:
28: Случайные выбросы – кратковременные скачки сигнала, вызванные помехами или плохим контактом.
29: Пропадание сигнала – кратковременное исчезновение данных.
30: 2.3. Методы диагностики
31: 1. Проверка диапазона (Range Check)
32: Простейший метод: значение должно находиться в допустимых пределах [min, max]. Если вышло – фиксируется отказ.
33: 2. Проверка скорости изменения (Rate of Change Check)
34: Физический процесс имеет ограниченную скорость изменения. Например, температура в резервуаре не может измениться на 50 °C за 1 секунду. Если скорость превышает порог – это либо отказ датчика, либо выброс помехи.
35: Формула: |x[k] − x[k−1]| / Δt ≤ V_max
36: 3. Проверка «залипания» (Stuck Detection)
37: Если значение не меняется в течение N циклов подряд, хотя в системе есть динамика (например, регулятор работает, а датчик не реагирует) – это признак «залипания».
38: 4. Мажоритарное голосование (2 из 3)
39: Если есть три датчика одного параметра, сравнивают их показания. Если один датчик существенно отклоняется от двух других – он неисправен. Медиана трёх значений принимается как достоверная.
40: 5. Фильтрация (Median, Kalman)
41: Медианный фильтр хорошо подавляет единичные выбросы. Фильтр Калмана позволяет оценить истинное значение параметра на основе модели процесса и зашумлённых измерений.
42: 6. Логический контроль
43: Проверка взаимосвязей между параметрами. Например, если давление в трубопроводе растёт, а расход падает – это физически противоречиво. Значит, один из датчиков неисправен.
44: 7. Анализ тренда
45: Если значение медленно смещается относительно ожидаемого (например, при постоянной нагрузке температура растёт, хотя не должна), это может быть дрейф нуля.

58: 4.2. Реализация имитатора датчика 
59: Создать файл sensor_simulator.py:
60: python
61: import numpy as np
62: import time
64: class SensorSimulator:
65:     """
66:     Имитатор датчика температуры.
67:     Генерирует нормальный сигнал с шумом.
68:     Позволяет вносить отказы по команде.
69:     """
70:     def __init__(self, nominal=50.0, noise=0.5):
71:         self.nominal = nominal          # номинальное значение
72:         self.noise = noise              # амплитуда шума
73:         self.fault_type = None          # тип отказа
74:         self.fault_start_time = None    # время начала отказа
75:         self.last_value = nominal       # последнее значение (для залипания)
76:         self.drift_offset = 0.0         # смещение при дрейфе
77:         self.start_time = time.time()
79:     def set_fault(self, fault_type, duration=10.0):
80:         """
81:         Внести отказ.
82:         fault_type: 'open', 'short', 'drift', 'stuck', 'spike'
83:         duration: длительность отказа в секундах
84:         """
85:         self.fault_type = fault_type
86:         self.fault_start_time = time.time()
87:         self.fault_duration = duration
89:     def clear_fault(self):
90:         """Сбросить отказ."""
91:         self.fault_type = None
92:         self.fault_start_time = None
93:         self.drift_offset = 0.0
95:     def read(self):
96:         """
97:         Прочитать значение датчика.
98:         Возвращает текущее значение (float).
99:         """
100:         t = time.time() - self.start_time
102:         # Проверка длительности отказа
103:         if self.fault_type is not None:
104:             elapsed = time.time() - self.fault_start_time
105:             if elapsed > self.fault_duration:
106:                 self.clear_fault()
108:         # Базовое значение с шумом
109:         value = self.nominal + np.random.normal(0, self.noise)
111:         # Внесение отказа
112:         if self.fault_type == 'open':
113:             # Обрыв: значение уходит в -50
114:             value = -50.0
116:         elif self.fault_type == 'short':
117:             # Короткое замыкание: значение 200
118:             value = 200.0
120:         elif self.fault_type == 'drift':
121:             # Дрейф: смещение нарастает со временем
122:             elapsed = time.time() - self.fault_start_time
123:             self.drift_offset = 0.5 * elapsed  # 0.5 °C/сек
124:             value += self.drift_offset
126:         elif self.fault_type == 'stuck':
127:             # Залипание: значение не меняется
128:             value = self.last_value
130:         elif self.fault_type == 'spike':
131:             # Случайный выброс
132:             value += np.random.choice([-30, 30])
134:         self.last_value = value
135:         return value
136: 4.3. Реализация алгоритма диагностики 
137: Создать файл diagnostics.py:
138: python
139: class SensorDiagnostics:
140:     """
141:     Алгоритм диагностики датчика.
142:     """
143:     def __init__(self, min_val=-40.0, max_val=150.0,
144:                  max_rate=5.0, stuck_threshold=10):
145:         self.min_val = min_val              # нижняя граница диапазона
146:         self.max_val = max_val              # верхняя граница
147:         self.max_rate = max_rate            # макс. скорость изменения (°C/сек)
148:         self.stuck_threshold = stuck_threshold  # число циклов для залипания
150:         self.prev_value = None
151:         self.prev_time = None
152:         self.stuck_counter = 0
153:         self.faults = []                    # список обнаруженных отказов
155:     def check(self, value, timestamp):
156:         """
157:         Проверить значение датчика.
158:         Возвращает список обнаруженных проблем (пустой, если всё ок).
159:         """
160:         problems = []
162:         # 1. Проверка диапазона
163:         if value < self.min_val or value > self.max_val:
164:             problems.append('out_of_range')
166:         # 2. Проверка скорости изменения
167:         if self.prev_value is not None and self.prev_time is not None:
168:             dt = timestamp - self.prev_time
169:             if dt > 0:
170:                 rate = abs(value - self.prev_value) / dt
171:                 if rate > self.max_rate:
172:                     problems.append('rate_exceeded')
174:         # 3. Проверка залипания
175:         if self.prev_value is not None:
176:             if abs(value - self.prev_value) < 0.001:
177:                 self.stuck_counter += 1
178:                 if self.stuck_counter >= self.stuck_threshold:
179:                     problems.append('stuck')
180:             else:
181:                 self.stuck_counter = 0
183:         # Сохранение предыдущих значений
184:         self.prev_value = value
185:         self.prev_time = timestamp
187:         # Запись отказов
188:         if problems:
189:             self.faults.append((timestamp, value, problems))
191:         return problems
192: 4.4. Реализация медианного фильтра 
193: Добавить в diagnostics.py:
194: python
195: class MedianFilter:
196:     """Медианный фильтр для подавления выбросов."""
197:     def __init__(self, window_size=5):
198:         self.window_size = window_size
199:         self.buffer = []
201:     def filter(self, value):
202:         self.buffer.append(value)
203:         if len(self.buffer) > self.window_size:
204:             self.buffer.pop(0)
205:         return float(np.median(self.buffer))
206: 4.5. Основной сценарий эксперимента 
207: Создать файл main.py:
208: python
209: import time
210: import matplotlib.pyplot as plt
211: from sensor_simulator import SensorSimulator
212: from diagnostics import SensorDiagnostics, MedianFilter
214: # Инициализация
215: sensor = SensorSimulator(nominal=50.0, noise=0.5)
216: diag = SensorDiagnostics(min_val=-40.0, max_val=150.0,
217:                           max_rate=5.0, stuck_threshold=10)
218: median = MedianFilter(window_size=5)
220: # Параметры эксперимента
221: duration = 60.0         # длительность эксперимента (сек)
222: dt = 0.1                # период опроса (сек)
224: # Задание отказов
225: schedule = [
226:     (15.0, 'drift', 10.0),   # на 15-й секунде – дрейф на 10 сек
227:     (35.0, 'open', 5.0),     # на 35-й секунде – обрыв на 5 сек
228:     (45.0, 'spike', 2.0),    # на 45-й секунде – выброс
229: ]
231: # Журналы
232: times = []
233: values_raw = []
234: values_filtered = []
235: faults_log = []
237: start = time.time()
238: next_fault = 0
240: while True:
241:     t = time.time() - start
242:     if t > duration:
243:         break
245:     # Проверка расписания отказов
246:     if next_fault < len(schedule):
247:         fault_time, fault_type, fault_dur = schedule[next_fault]
248:         if t >= fault_time:
249:             sensor.set_fault(fault_type, fault_dur)
250:             print(f"[{t:.1f}s] Внесён отказ: {fault_type}")
251:             next_fault += 1
253:     # Чтение значения
254:     raw = sensor.read()
255:     filtered = median.filter(raw)
257:     # Диагностика по отфильтрованному значению
258:     problems = diag.check(filtered, t)
259:     if problems:
260:         print(f"[{t:.1f}s] Обнаружен отказ: {problems}, значение = {filtered:.2f}")
261:         faults_log.append((t, problems, filtered))
263:     # Запись в журналы
264:     times.append(t)
265:     values_raw.append(raw)
266:     values_filtered.append(filtered)
268:     time.sleep(dt)
270: # Построение графиков
271: fig, ax = plt.subplots(2, 1, figsize=(12, 8))
273: ax[0].plot(times, values_raw, 'b-', alpha=0.5, label='Сырой сигнал')
274: ax[0].plot(times, values_filtered, 'r-', label='Медианный фильтр')
275: ax[0].axhline(y=150, color='k', linestyle='--', label='Верхняя граница')
276: ax[0].axhline(y=-40, color='k', linestyle='--', label='Нижняя граница')
277: ax[0].set_xlabel('Время, с')
278: ax[0].set_ylabel('Значение, °C')
279: ax[0].legend()
280: ax[0].grid(True)
282: # Отметки отказов
283: for t_fault, probs, val in faults_log:
284:     ax[0].axvline(x=t_fault, color='red', alpha=0.3)
286: ax[1].plot(times, [0 if i not in [f[0] for f in faults_log] else 1
287:                    for i in times], 'r-')
288: ax[1].set_xlabel('Время, с')
289: ax[1].set_ylabel('Флаг отказа')
290: ax[1].grid(True)
292: plt.tight_layout()
293: plt.savefig('diagnostics_result.png', dpi=150)
294: plt.show()
296: # Итоги
297: print(f"\nВсего обнаружено отказов: {len(faults_log)}")
298: for t, probs, val in faults_log:
299:     print(f"  t = {t:.1f} с, тип = {probs}, значение = {val:.2f}")

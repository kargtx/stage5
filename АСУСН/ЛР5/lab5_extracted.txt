11: 2. Теоретическая часть
12: 2.1. Роль промышленных сетей в АС СН
13: Промышленные сети – это «нервная система» АС СН. Они связывают датчики, контроллеры, SCADA-серверы и исполнительные механизмы, обеспечивая обмен данными в реальном времени. От правильного выбора сети зависят надёжность, быстродействие и стоимость системы.
14: К промышленным сетям предъявляются особые требования:
15: Детерминизм – гарантированное время доставки сообщений;
16: Помехоустойчивость – работа в условиях электромагнитных помех;
17: Надёжность – способность работать годами без сбоев;
18: Совместимость – поддержка стандартных протоколов;
19: Масштабируемость – возможность добавлять новые устройства.
20: 2.2. Протокол Modbus
21: Modbus – один из самых распространённых промышленных протоколов. Разработан в 1979 году компанией Modicon (ныне Schneider Electric). Открытый, простой, широко поддерживается.
22: Принцип работы:
23: Архитектура «ведущий–ведомый» (Master-Slave);
24: Один ведущий (Master) опрашивает несколько ведомых (Slave);
25: Ведомый отвечает только на запросы, инициированные ведущим.
26: Типы данных Modbus:
27: Функции Modbus (основные):
29: Форматы передачи:
30: Modbus RTU – последовательный (RS-485), двоичный формат, CRC-проверка;
31: Modbus ASCII – последовательный, текстовый формат;
32: Modbus TCP – по Ethernet, порт 502, без CRC (используется TCP-контроль).
33: Структура кадра Modbus TCP:
34: text
35: [Transaction ID (2 байта)][Protocol ID (2)][Length (2)][Unit ID (1)][Function (1)][Data (N)]
36: 2.3. Протокол CAN
37: CAN (Controller Area Network) – разработан компанией Bosch в 1983 году для автомобильной промышленности. Сейчас широко применяется в промышленности, робототехнике, медицине.
38: Принцип работы:
39: Многоабонентская шина (multimaster);
40: Каждый узел может передавать сообщения, когда шина свободна;
41: Арбитраж по приоритету – если два узла одновременно начинают передачу, побеждает тот, у кого меньше ID (доминирующие биты).
42: Структура CAN-кадра:
43: text
44: [SOF][Arbitration ID (11 или 29 бит)][RTR][IDE][DLC (4 бита)][Data (0-8 байт)][CRC][ACK][EOF]
45: Скорость: до 1 Мбит/с (классический CAN), до 8 Мбит/с (CAN FD).
46: Особенности CAN:
47: Максимальный размер данных – 8 байт (для классического CAN);
48: Встроенная проверка ошибок (CRC, ACK, bit monitoring);
49: Автоматическая повторная передача при ошибке;
50: Приоритетный доступ – гарантирует доставку важных сообщений в первую очередь.
51: 2.4. Протокол Profibus
52: Profibus (Process Field Bus) – стандарт, разработанный Siemens в 1989 году. Два варианта:
53: Profibus DP (Decentralized Peripherals) – для связи с полевыми устройствами, скорость до 12 Мбит/с;
54: Profibus PA (Process Automation) – для взрывоопасных зон, скорость 31.25 кбит/с.
55: Особенности:
56: Топология – линейная шина;
57: Архитектура «ведущий–ведомый» с несколькими ведущими (multi-master);
58: Циклический обмен + ациклический (для параметрирования);
59: Максимальная длина сегмента – 1200 м (при скорости 93.75 кбит/с).

81: 4.2.1. Реализация Modbus-сервера (эмулятор ПЛК)
82: Создать файл modbus_server.py:
83: python
84: from pymodbus.server import StartTcpServer
85: from pymodbus.datastore import (
86:     ModbusSequentialDataBlock,
87:     ModbusSlaveContext,
88:     ModbusServerContext
89: )
90: import threading
91: import time
92: import random
94: # Инициализация хранилища данных
95: # DI - дискретные входы, CO - катушки, HR - holding registers, IR - input registers
96: store = ModbusSlaveContext(
97:     di=ModbusSequentialDataBlock(0, [0]*100),
98:     co=ModbusSequentialDataBlock(0, [0]*100),
99:     hr=ModbusSequentialDataBlock(0, [0]*100),
100:     ir=ModbusSequentialDataBlock(0, [0]*100)
101: )
103: context = ModbusServerContext(slaves=store, single=True)
106: def update_registers():
107:     """
108:     Фоновая задача: имитирует изменение значений датчиков.
109:     Обновляет Holding Registers каждую секунду.
110:     """
111:     while True:
112:         # Температура (HR[0]), значение 40-60 °C
113:         temp = random.uniform(40, 60)
114:         store.setValues(3, 0, [int(temp * 10)])  # умножено на 10 для точности
116:         # Давление (HR[1]), значение 5-8 бар
117:         pressure = random.uniform(5, 8)
118:         store.setValues(3, 1, [int(pressure * 100)])
120:         # Уровень (HR[2]), значение 30-70 %
121:         level = random.uniform(30, 70)
122:         store.setValues(3, 2, [int(level)])
124:         # Дискретный вход (DI[0]) – сигнал «Авария»
125:         alarm = 1 if temp > 55 or pressure > 7.5 else 0
126:         store.setValues(2, 0, [alarm])
128:         # Coil (CO[0]) – команда «Пуск насоса» (устанавливается клиентом)
129:         # Coil (CO[1]) – команда «Стоп насоса»
131:         time.sleep(1.0)
134: if __name__ == '__main__':
135:     # Запуск фонового обновления
136:     updater = threading.Thread(target=update_registers, daemon=True)
137:     updater.start()
139:     print("Modbus TCP сервер запущен на 127.0.0.1:502")
140:     print("HR[0] = Температура x10, HR[1] = Давление x100, HR[2] = Уровень")
141:     print("DI[0] = Авария, CO[0] = Пуск насоса, CO[1] = Стоп насоса")
143:     StartTcpServer(context, address=("127.0.0.1", 502))
144: Важно: порт 502 требует прав администратора. Если прав нет, используйте порт 5020 и укажите его в клиенте.
145: 4.2.2. Реализация Modbus-клиента (эмулятор SCADA)
146: Создать файл modbus_client.py:
147: python
148: from pymodbus.client import ModbusTcpClient
149: import time
150: import matplotlib.pyplot as plt
152: # Подключение к серверу
153: client = ModbusTcpClient('127.0.0.1', port=5020)
154: client.connect()
156: # Журналы для графиков
157: times = []
158: temps = []
159: pressures = []
160: levels = []
161: alarms = []
163: start_time = time.time()
164: duration = 30  # секунд
166: try:
167:     while time.time() - start_time < duration:
168:         t = time.time() - start_time
170:         # Чтение Holding Registers (функция 3)
171:         hr_response = client.read_holding_registers(0, 3, slave=1)
172:         if not hr_response.isError():
173:             temp = hr_response.registers[0] / 10.0
174:             pressure = hr_response.registers[1] / 100.0
175:             level = hr_response.registers[2]
176:         else:
177:             print("Ошибка чтения HR")
178:             temp = pressure = level = None
180:         # Чтение Discrete Inputs (функция 2)
181:         di_response = client.read_discrete_inputs(0, 1, slave=1)
182:         alarm = di_response.bits[0] if not di_response.isError() else None
184:         # Запись команды "Пуск насоса" при уровне < 40%
185:         if level is not None and level < 40:
186:             client.write_coil(0, True, slave=1)
187:             print(f"[{t:.1f}с] Уровень {level}% – отправлена команда ПУСК")
188:         elif level is not None and level > 60:
189:             client.write_coil(1, True, slave=1)
190:             print(f"[{t:.1f}с] Уровень {level}% – отправлена команда СТОП")
192:         # Запись в журналы
193:         if temp is not None:
194:             times.append(t)
195:             temps.append(temp)
196:             pressures.append(pressure)
197:             levels.append(level)
198:             alarms.append(alarm)
199:             print(f"[{t:.1f}с] T={temp:.1f}°C, P={pressure:.2f}бар, L={level}%, Alarm={alarm}")
201:         time.sleep(0.5)
203: finally:
204:     client.close()
206: # Построение графиков
207: fig, axes = plt.subplots(4, 1, figsize=(12, 10))
209: axes[0].plot(times, temps, 'r-')
210: axes[0].set_ylabel('Температура, °C')
211: axes[0].grid(True)
213: axes[1].plot(times, pressures, 'b-')
214: axes[1].set_ylabel('Давление, бар')
215: axes[1].grid(True)
217: axes[2].plot(times, levels, 'g-')
218: axes[2].set_ylabel('Уровень, %')
219: axes[2].grid(True)
221: axes[3].plot(times, alarms, 'k-')
222: axes[3].set_ylabel('Авария')
223: axes[3].set_xlabel('Время, с')
224: axes[3].grid(True)
226: plt.tight_layout()
227: plt.savefig('modbus_result.png', dpi=150)
228: plt.show()

246: 4.3. Часть B. Эмуляция CAN 
247: 4.3.1. Реализация двух CAN-узлов
248: Создать файл can_nodes.py:
249: python
250: import can
251: import time
252: import threading
253: import random
254: import matplotlib.pyplot as plt
256: # Создание виртуальной CAN-шины
257: bus = can.interface.Bus(interface='virtual', channel='vcan0')
259: # Журналы
260: received_messages = []
261: times = []
262: temps_from_can = []
265: def sensor_node():
266:     """
267:     Узел 1: Датчик температуры.
268:     Отправляет сообщение с ID 0x100 каждые 500 мс.
269:     """
270:     msg_id = 0x100
271:     start = time.time()
273:     while time.time() - start < 30:
274:         temp = random.uniform(40, 60)
275:         data = list(int(temp * 10).to_bytes(2, byteorder='big'))
276:         msg = can.Message(
277:             arbitration_id=msg_id,
278:             data=data,
279:             is_extended_id=False
280:         )
281:         bus.send(msg)
282:         print(f"[Датчик] Отправлено: ID=0x{msg_id:X}, T={temp:.1f}°C")
283:         time.sleep(0.5)
286: def actuator_node():
287:     """
288:     Узел 2: Исполнительный механизм.
289:     Принимает сообщения с ID 0x100 (температура)
290:     и 0x200 (команды управления).
291:     """
292:     start = time.time()
294:     while time.time() - start < 30:
295:         msg = bus.recv(timeout=1.0)
296:         if msg is None:
297:             continue
299:         t = time.time() - start
301:         if msg.arbitration_id == 0x100:
302:             # Приём температуры
303:             temp = int.from_bytes(msg.data[:2], byteorder='big') / 10.0
304:             times.append(t)
305:             temps_from_can.append(temp)
306:             print(f"[Механизм] Принято: ID=0x{msg.arbitration_id:X}, T={temp:.1f}°C")
308:             # Если температура > 55 – отправить команду "Авария"
309:             if temp > 55:
310:                 alarm_msg = can.Message(
311:                     arbitration_id=0x200,
312:                     data=[0x01],
313:                     is_extended_id=False
314:                 )
315:                 bus.send(alarm_msg)
316:                 print(f"[Механизм] Отправлена аварийная команда: ID=0x200")
318:         elif msg.arbitration_id == 0x200:
319:             print(f"[Механизм] Принята команда: ID=0x{msg.arbitration_id:X}, data={list(msg.data)}")
321:         received_messages.append(msg)
324: if __name__ == '__main__':
325:     print("Запуск CAN-эмуляции на виртуальной шине vcan0")
326:     print("Узел 1 (ID=0x100) – датчик температуры")
327:     print("Узел 2 – исполнительный механизм (принимает 0x100, отправляет 0x200)")
329:     # Запуск двух потоков
330:     t1 = threading.Thread(target=sensor_node)
331:     t2 = threading.Thread(target=actuator_node)
333:     t1.start()
334:     t2.start()
336:     t1.join()
337:     t2.join()
339:     # График
340:     if times:
341:         plt.figure(figsize=(10, 5))
342:         plt.plot(times, temps_from_can, 'r-o', markersize=3)
343:         plt.axhline(y=55, color='k', linestyle='--', label='Порог аварии')
344:         plt.xlabel('Время, с')
345:         plt.ylabel('Температура, °C')
346:         plt.title('Данные, полученные по CAN-шине')
347:         plt.legend()
348:         plt.grid(True)
349:         plt.savefig('can_result.png', dpi=150)
350:         plt.show()
352:     print(f"\nВсего принято сообщений: {len(received_messages)}")
